# Telegram бот подписок на приватный канал

Функции:
- Покупка подписки кнопками: **90 дней (9999 ₽)** и **1 год (14999 ₽)**.
- Бот отправляет реквизиты для оплаты (СПБ перевод на карту).
- Клиент отправляет скрин/чек в чат бота.
- Бот пересылает чек админам с кнопками **Подтвердить/Отклонить**.
- После подтверждения бот выдает **одноразовую** ссылку на приватный канал.
- Авто-напоминания перед окончанием подписки (примерно за 7 дней и за 1 день).
- По истечении срока бот удаляет пользователя из канала.
- Админ-меню: статистика и смена номера карты.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните BOT_TOKEN, ADMIN_IDS, PRIVATE_CHANNEL_ID
python bot.py
```

## Важно
- Бот должен быть админом в приватном канале (права на создание инвайтов и удаление участников).
- Для обработки платежей используется ручная модерация администратором.
