# Telegram бот платной подписки на приватный канал

Бот реализует сценарий продажи подписки с ручной проверкой оплаты администратором.

## Что умеет
- Кнопки для пользователя:
  - Купить `90 дней — 5999 ₽`
  - Купить `1 год — 14999 ₽`
  - Проверить статус подписки
- Оплата через перевод по реквизитам карты, которые бот отправляет в чате.
- Пользователь присылает скрин/чек, бот отправляет его админам.
- У админа под чеком кнопки:
  - ✅ Подтвердить
  - ❌ Отклонить
- После подтверждения пользователь получает одноразовую ссылку в приватный канал.
- За ~7 дней и ~1 день до окончания подписки бот отправляет напоминание.
- После истечения срока бот отключает доступ к каналу.
- Админ-меню:
  - Статистика
  - Список ожидающих оплат
  - Смена номера карты через кнопку

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
cp .env.example .env
# Заполните BOT_TOKEN, ADMIN_IDS, PRIVATE_CHANNEL_ID
python bot.py
```

## Важно про Python
- Рекомендуемая версия: **Python 3.11 или 3.12**.
- Если на Windows при старых пакетах возникает зависание/ошибка на `from aiogram import ...`:
  1. Удалите старые зависимости: `pip uninstall -y aiogram pydantic pydantic-core aiohttp`
  2. Поставьте версии из `requirements.txt`: `pip install -r requirements.txt`

## Переменные окружения
Смотрите `.env.example`:
- `BOT_TOKEN` — токен Telegram-бота
- `ADMIN_IDS` — список id админов через запятую
- `PRIVATE_CHANNEL_ID` — id приватного канала
- `DB_PATH` — путь к SQLite базе
- `DEFAULT_CARD_NUMBER` — карта по умолчанию
- `USER_TIMEZONE` — таймзона для отображения дат пользователю (по умолчанию `Europe/Moscow`)

## Важно
- Бот должен быть админом в канале с правами:
  - создание invite-ссылок
  - удаление участников
